# CalificaApp

## Ceniceros Uribe Jean Carlos

#### En este proyecto se intenta dar la impresion de una aplicacion que matiene el control escolar la cual llevara trabajando con 3 diferentes modulos por el momento, los cuales seran Alumnos, Maestros y materias, cada uno con su correspondiente formulario y cada uno con las funciones del CRUD (Crear, Leer Actualizar y Borrar) que son la idea principal de todo esto.
